# Data folder

The real dataset used in this project is **proprietary to the company** where the
author completed a co-op internship. It is **not included** in this repository.

## Expected file

If you have your own registration data with the same structure, save it as:

    data/registrations.csv

Columns (one row per event registration):

| Column        | Type    | Allowed values / meaning                                                     |
|---------------|---------|------------------------------------------------------------------------------|
| `STATUS`      | integer | Target. 1 = no-show, 0 = attended                                            |
| `COUNTRY`     | integer | 1 = domestic registrant, 0 = international                                   |
| `JOB`         | factor  | Job group (7 levels, see main README). Reference level: `Technical Roles`    |
| `LEADTIME`    | integer | Days between registration date and event date                                |
| `TIME_ATTEND` | integer | 1 = returning attendee (attended this event 2-3 times), 0 = first-time      |
| `COMPANYSIZE` | integer | 1 = company with more than 500 employees, 0 = fewer than 500                 |

## Synthetic data (for testing the code only)

`synthetic_registrations.csv` is randomly generated by `R/generate_synthetic_data.R`.
It has the same columns as above but contains **no real people and no real
company records**. Results from it are meaningless and will not match the report.
